# QvQMemes

**[QvQChat](https://github.com/wsu2059q/ErisPulse-QvQChat) エージェントのためのスタンプシステム：グループチャットを傍受して勝手に収集し、ビジョンモデルが自動でタグ付けし、いつ送るか・どれを送るかは AI が自分で決める。**

世の中の「ミーム系プラグイン」の多くはパチスロのようなものです。メッセージが来たらサイコロを振り、フォルダからランダムに一枚取り出す。出てきたものと、今実際に交わされている会話とは何の関係もありません。このモジュールは真逆の立場を取ります。ここでのスタンプはエージェントの表現の一部であり、ライブラリから出て行く経路は二つあります。`send_sticker` ツール——QvQChat のエコシステムブリッジがごく普通の AI ツールとして登録するもの。そして返信本文に書くインラインマーカー `[表情:キーワード]`——QvQChat 4.6.7 以降は配信層が本物のスタンプに置き換えるため、ツール呼び出しは不要です。今この瞬間にスタンプを送るべきか（軽いツッコミ、感情のひとコマ、一言のお返し）は完全にモデルの判断で、手がかりはツール説明の一文（「カジュアル・からかい・感情表現の場面に適する。真面目なタスクでは控えめに」）だけです。パイプラインのどこにもタイマーもサイコロもありません。これが「ランダム画像合戦」系プラグインとの本質的な違いであり、意図した設計です。

「どれを送るか」も同じやり方で決まります。モデルが意味クエリ（「得意げな猫」「丁寧にお礼」）を出し、モジュールがライブラリ内の各スタンプの説明とタグに対して決定論的な字面マッチングで採点します——タグ完全一致は 4 点、タグ部分一致は 2 点、説明ヒットは 3 点を語ごとに加算——そして最高得点の一枚を送ります。収集も同じく手作業なしです。グループチャットを流れる画像は QvQChat の `qvq.observe` イベント経由で拾われ、ビジョンモデルが一枚ずつ眺めて、内容と感情を一行で説明し、3〜6 個の使用シーンタグを書き込みます。誰もラベル付けをしません。モジュールが順序に手を加えるのは「新鮮度の減点」だけです。`recency_hours` のウィンドウ内に送ったスタンプは検索スコアが半減し、エージェントが同じ画像を一週間使い回さないようにします。これは決定論的なスケジューリングであって確率ではありません——最近使ったものを減点し、ライブラリが一杯なら最久未使用のものから追い出す。それ以外の何ものも順序を乱しません。

## インストール

[QvQChat](https://github.com/wsu2059q/ErisPulse-QvQChat) 4.0.4 以降が必要です（このモジュールが利用する `qvq.observe` イベントとプラグイン設定ページは、そのバージョンで導入されました）。ErisPulse 2.8.0+ が前提です。

```bash
epsdk install ErisPulse-QvQMemes
# または
pip install ErisPulse-QvQMemes
```

## 有効化

有効化の作業はありません。モジュールが読み込まれると、エコシステムブリッジがそのサービスを自動的に AI ツールへ変換します。エージェントは `send_sticker` に加えて `sticker_search`、`sticker_stats`、`sticker_add` を手に入れ、アンインストール時には同じく静かに手放します。設定項目は QvQChat ダッシュボードの設定ページにあるプラグイン欄に現れます。

スタンプライブラリはデフォルトで `data/QvQMemes/stickers` に置かれます。チャットから収集した画像は内容ハッシュの先頭 16 桁（十六進）で名前を付けられてここにダウンロードされ、起動のたびにモジュールがディレクトリを走査して、自分で放り込んだ画像も取り込んでいきます。手持ちのスタンプフォルダを種として放り込むのも、まったく正当な使い方です。

## 仕組み

収集はバイパス経路で動き、チャットのメインパイプラインを決してブロックしません。QvQChat が `qvq.observe` をブロードキャストすると（見えたすべてのグループメッセージ、1 通につき最大 3 枚）、モジュールはペイロードを素早く検証して作業をバックグラウンドタスクに投げます。このタスクはまず URL と内容ハッシュの二重フィンガープリントで重複を除外し、チャットごとの一日上限を確認し、残りを直列でダウンロードして保存します——ダウンロードに失敗しても URL 参照を保持するため、スタンプはそのまま送信できます——それからビジョンによるタグ付けのキューに並べます。タグ付けは QvQChat の `describe_image` 経由で行われ、ビジョンモデルがない場合や呼び出しに失敗した場合は、エントリをひとまず「未分類」として記録し、説明文による検索には引き続き参加できます。このパイプラインに致命的な段階は一つもありません。全エントリは `{id, path, url, desc, tags, source, uses, last_used, added}` の形でフレームワークのキーバリューストレージに格納されます。

送信はプラットフォームアダプタの SendDSL を通るため、フレームワークが対応するどのプラットフォームでも同じ挙動になります。

```python
# モデルが send_sticker ツールを呼び出したとき、エコシステムブリッジが実際に実行するもの：
await sdk.module.call("QvQMemes", "send_sticker",
                      query="得意げな猫 優越",
                      platform="qqbot",
                      target_id="123456",
                      target_type="group")
# -> "Sent: a smug white cat rolling its eyes | smug teasing comeback"
```

一致するものがないときは、その旨とライブラリの高頻度タグを返します。モデルは黙って失敗するのではなく、言い換えて再試行できます。

## 設定

設定項目はモジュールの ConfigClass で宣言され、QvQChat の設定ページに自動的にフォームとして表示されます。実行時の値はロード時に `QvQChat.plugin_config` 経由で引き戻され、失敗した場合は黙ってデフォルトを使い続けます。

| キー | デフォルト | 説明 |
|------|---------|-------------|
| `library_dir` | `data/QvQMemes/stickers` | ライブラリディレクトリ。ダウンロードはここに置かれ、既存の画像は起動時にスキャンして取り込まれる |
| `max_library` | `500` | ライブラリの容量上限。超過分は最久未使用のものから追い出す（未使用のものは追加時刻で数える） |
| `recency_hours` | `72` | 新鮮度ウィンドウ（時間）。ウィンドウ内に送ったスタンプは検索スコアが半減 |
| `send_method` | `Image` | 送信に使う SendDSL メソッド（画像 URL またはローカルパス） |
| `auto_collect` | `True` | `qvq.observe` のペイロードから画像を収集（1 メッセージにつき最大 3 枚） |
| `collect_per_chat_daily` | `20` | チャットごとの一日あたり収集上限。0 以下で無制限 |
| `tag_via_vision` | `True` | 収集後に QvQChat のビジョンモデルでタグ付け。利用できない場合は「未分類」として記録 |

## サービス

5 つのサービスはすべて `get_meta().services` のホワイトリストに載っています。戻り値は str か dict だけで、例外は決して投げません。内部エラーはすべて読めるテキストか `error` フィールドに変換されるため、モデルは必ず次の行動に使える答えを受け取ります。

| サービス | シグネチャ | 説明 |
|---------|-----------|-------------|
| `send_sticker` | `(query: str, platform: str, target_id: str, target_type: str = "group") -> str` | 意味クエリに最も合う一枚を選んで送信。成功時は "Sent: \<desc\>"、一致なしの場合は利用可能タグのヒント、失敗時はエラーテキストを返す |
| `sticker_search` | `(query: str, top_n: int = 5) -> dict` | 送信せず検索のみ：`{query, count, results: [{id, desc, tags, score, url, path, uses}], tag_hints}` |
| `sticker_stats` | `() -> dict` | ライブラリ統計：`{total, max_library, untagged, added_today, tag_distribution, top_used}` |
| `sticker_add` | `(url: str = '', path: str = '', desc: str = '', tags: str = '') -> str` | URL またはローカルパスで手動収録。desc/tags の省略時はビジョンによるタグ付けに委ねる |
| `qvq_settings` | `() -> dict` | 帰属マーカー `{"title": ...}`。このサービスを宣言したモジュールだけが QvQChat 設定ページのプラグイン欄に現れる |
